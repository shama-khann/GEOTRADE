# GEOTRADE
GEOTRADE is a real-time financial intelligence system that reads live news , runs it  through a local AI pipeline to measure geopolitical stress, then  predicts how world events will affect stock markets, gold, oil,  currencies and crypto — all displayed on a live 3D globe and  interactive world map.
